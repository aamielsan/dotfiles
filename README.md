# dotfiles

My macOS setup as a single [mise](https://mise.jdx.dev) config. This repo **is**
`~/.config/mise`: `mise bootstrap` reads it and installs tools and apps, links
dotfiles, clones my Neovim config and applies macOS settings. No Homebrew, no
install scripts.

## New machine

1. Install the Xcode Command Line Tools (git, C compiler):
   ```sh
   xcode-select --install
   ```
2. Install mise:
   ```sh
   curl https://mise.run | sh
   ```
3. Clone this repo into `~/.config/mise` and apply it. On a work laptop add
   `-E work` (see [Modules](#modules)):
   ```sh
   ~/.local/bin/mise -E work bootstrap --adopt aamielsan/dotfiles
   ```
   It asks for your password once (app installs need sudo). If it stops because
   a dotfile already exists as a real file, move that file away and run it again.
4. Remember the module choice for this machine, so plain `mise bootstrap` works:
   ```sh
   echo 'env = ["work"]' > ~/.config/mise/miserc.local.toml
   ```
5. Open Ghostty, log out and back in (trackpad settings), then do the
   [manual steps](#manual-steps).

## Day to day

| I want to… | Do this |
|---|---|
| Re-apply everything after editing | `mise bootstrap` (`--dry-run` first to preview) |
| See what differs from the config | `mise bootstrap status` |
| Add a CLI tool | `mise use -g <tool>` (writes to `config.toml`), commit |
| Update tools | `mise upgrade`, then `mise bootstrap` (repoints the Docker buildx plugin), commit `mise.lock` / `mise.work.lock` |
| Add a dotfile | put it in `home/`, add a line under `[dotfiles]`, `mise bootstrap` |
| Add a GUI app | add `"brew-cask:<name>" = {}` under `[bootstrap.packages]` ([find names](https://formulae.brew.sh/cask/)) |
| Edit a dotfile | edit it in place (`~/.zshrc` etc. are symlinks into `home/`) |

GUI apps update themselves; mise only installs them.

## Layout

| Path | What |
|---|---|
| `config.toml` | Shared setup for every machine: tools, apps, dotfiles, macOS settings |
| `config.work.toml` | The `work` module: DNB-only tools, aliases, git identity, SSH host |
| `home/` | Dotfile sources, mirroring `$HOME` |
| `mise.lock`, `mise.work.lock`, `locks/` | Exact tool versions and checksums. Generated by mise; commit them |
| `miserc.local.toml` | Per-machine module choice. Not committed |

## Modules

A module is a `config.<name>.toml` file that only applies on machines that
choose it. Currently there's one, `work`. A machine picks modules in
`~/.config/mise/miserc.local.toml`:

```toml
env = ["work"]
```

To add one (e.g. `personal`), create `config.personal.toml` and list it there.
To remove a module from a machine: drop it from `env`, then
`mise bootstrap unapply <name>`.

Things that only some machines have hook in through files that may or may not
exist: `.zshrc` sources `~/.aliases.work` if present, `.gitconfig` includes
`~/.gitconfig.work` for repos under `~/workspace/dnb/`, and `~/.ssh/config`
includes everything in `~/.ssh/config.d/`.

## What's set up where

- **Shell:** zsh with [Zim](https://zimfw.sh) (modules in `home/.zimrc`, it
  installs itself on first start). `.zprofile` sets environment and PATH,
  `.zshrc` does interactive setup. fzf (Ctrl-R, Ctrl-T) and zoxide (`z <dir>`).
- **Terminal:** Ghostty opens straight into the tmux session `default`.
- **Workspace:** repos go in `~/workspace/personal/` (every machine) or
  `~/workspace/dnb/` (work; uses the work git identity), one folder per repo.
- **Git:** `home/.gitconfig`, global ignore in `home/.config/git/ignore`.
- **Neovim:** config lives in its own repo,
  [aamielsan/nvim](https://github.com/aamielsan/nvim), cloned to
  `~/.config/nvim`. mise provides Neovim and the runtimes; Mason (inside
  Neovim) installs language servers and formatters.
- **Claude Code:** installed by mise (raicode can only install it with
  Homebrew). At work, launch it through `raicode`.
- **Containers:** `colima start` before using Docker (it isn't started
  automatically). For amd64-only images, `colima start --vz-rosetta`.

## Files other tools write

These live outside the repo on purpose. Each tool creates and owns its own:

| Path | Written by |
|---|---|
| `~/.zshenv`, `~/.raicode/` | `raicode manage fix-certs` (Zscaler certificate, work laptop only) |
| `~/.colima/` | Colima: the VM and its settings |
| `~/.docker/config.json` | Docker: registry credentials |
| `~/.zim/` | Zim: modules, downloaded on first shell start |
| `~/.local/share/nvim/` | Neovim: plugins, Mason servers, treesitter parsers |
| `~/.local/share/mise/`, `~/.local/state/mise/` | mise: installed tools and bootstrap state |

Two catches:

- Colima writes an `Include` into `~/.ssh/config`, which is a file in this
  repo. Start it the first time with `colima start --ssh-config=false`; it
  remembers the setting.
- `fix-certs` only edits `~/.zshenv` on its first run. If that line goes
  missing, move `~/.raicode/env.sh` away and run `fix-certs` again.

## Manual steps

- Caps Lock → Escape: System Settings → Keyboard → Keyboard Shortcuts →
  Modifier Keys.
- SSH keys: put `github-personal` (and `github-dnb` at work) in `~/.ssh/` and
  add the `.pub` to each GitHub account. Check with `ssh -T git@github.com` and
  `ssh -T dnb@dnb.ghe.com` (the DNB host's SSH user is `dnb`, not `git`).
- IntelliJ: point the project SDK at `~/.local/share/mise/installs/java/corretto-25`.
- Work laptop: run `raicode` to sign in, then `raicode manage fix-certs` and
  open a new terminal.
